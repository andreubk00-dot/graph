# HELIOS · Graph Forge showcase

Парящий механический реактор: сегментированный корпус, четыре раскрывающиеся бронепанели, вращающийся подвес кристалла, трубопроводы и док-станция. Это художественный игровой prop; механические допуски, коллизии и физика реактора не моделируются.

## Посмотреть

- `helios.png` — основной рендер.
- `helios.gif` — шестисекундный цикл работы реактора.
- `helios-viewer.html` — автономный интерактивный просмотрщик. Скачай файл и открой в браузере; сервер, CDN и интернет не нужны. Можно вращать модель, выбирать два клипа, менять время и включать каркас. Требуется WebGL; при ошибке остаётся сохранённый PNG. Сам интерактивный запуск в облачном Chromium не проверен: его запуск запрещён песочницей.
- `helios-icon.gif` — 16 кадров пиксельной иконки, увеличенных строго nearest-neighbor.
- `helios-emblem.svg` — векторная эмблема для интерфейса.

## Редактировать и импортировать в игру

`helios.graph.json` открой кнопкой загрузки JSON в Graph Forge. Все 206 узлов, 197 полигональных деталей, материалы, иерархия и два клипа редактируются. `Orbit` длится 6 секунд; `Deploy` — 3 секунды и не зациклен в редакторе. В игровом движке режим повторения задаётся отдельно. В сцене 31 324 треугольника; единицы — метры, +Y вверх, +Z вперёд.

`helios.glb` содержит настоящую геометрию, PBR-материалы с emission и оба клипа. Источник содержит канонические сетки и объектную анимацию. У этого примера нет текстур, скелетного скиннинга, LOD и коллизий. Отдельный `dock-profile.json` сохраняет исходный профиль lathe; для поставки док запечён штатным конвертером с удалением нулевых треугольников на полюсах.

`helios-icon.art.json` — отдельный 2D-проект: 96×96, три слоя на кадр, палитра, 16 кадров по 125 мс. PNG и atlas сохраняют исходные пиксели и прозрачность; GIF содержит тёмную подложку только для предпросмотра. Метаданные atlas соответствуют исходным кадрам и padding. `helios-emblem.art.json` — редактируемые векторные пути и градиенты.

## Что именно показывает изображение

Геометрия, материалы и анимация созданы командами/сборщиками Graph Forge и экспортированы его общим GLB-экспортёром. PNG/GIF — рендер этого GLB в **Blender**, поскольку облачная песочница не запускает Chromium/WebGL. Студийные источники света, пол и оптическое свечение относятся к презентации и не включены в GLB. Это не скриншот редактора и не генерация изображения по тексту. GIF — облегчённое превью; точные нормали и материалы лучше оценивать в интерактивном GLB.

`verification.json` фиксирует проверку всех сеток после GLB-импорта: численно одинаковые позиции/нормали/UV и индексы, отсутствие открытых/неманифолдных рёбер, конфликтов обхода, нулевых треугольников и ошибок нормалей. Для обоих клипов сравниваются мировые матрицы всех узлов в пяти моментах времени. Это проверка переноса данных, не сертификация художественного качества или импорта в конкретную игру.

## Воспроизвести из репозитория

```bash
node scripts/build-helios.js
node scripts/build-helios-art.js
node scripts/verify-helios.js
blender -b --factory-startup --python scripts/render-helios.py -- examples/helios still BLENDER_EEVEE_NEXT
blender -b --factory-startup --python scripts/render-helios.py -- examples/helios animate BLENDER_EEVEE_NEXT
node scripts/build-helios-viewer.js
ffmpeg -y -framerate 8 -i examples/helios/frames/%03d.png -filter_complex '[0:v]hqdn3d=6:6:9:9,split[a][b];[a]palettegen=stats_mode=diff[p];[b][p]paletteuse=dither=sierra2_4a' -loop 0 examples/helios/helios.gif
python3 scripts/package-helios.py
```

Основной PNG использует Eevee, работающий здесь через программный OpenGL. В скрипте также доступен CPU Cycles; дистрибутивный Blender собран без OpenImageDenoise. Видео проходит обычное шумоподавление при GIF-кодировании. Для более чистого офлайн-рендера увеличь число samples в `render-helios.py`. Статичный PNG имеет большее разрешение и больше samples, чем GIF.
